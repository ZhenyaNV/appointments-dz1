# Пересборка отчёта

Готовые DOCX и PDF находятся в корне «дз1». Для запуска сервиса генератор отчёта не нужен.

Генератор `build_report.py` читает исходный шаблон, `results/measurements.json`, `results/host.json`, итоговый журнал тестов и два скриншота. Нужен Python с python-docx 1.2.0. В текущей работе использована встроенная среда документов Codex.

```bash
python report/build_report.py
```

Автоматическое содержание представляет собой поле TOC, которое можно обновлять в Word. При автоматической сборке `update_toc.py путь_к_рендеру.pdf` генерирует его кеш по заголовкам и проверенным страницам PDF, без ручного набора содержания. После изменения состава страниц следует повторить рендер и обновление.

После пересборки откройте DOCX в Word и обновите содержание: выделить всё и обновить поля (на Mac — Cmd+A, затем F9 или Fn+F9). Сохраните документ. PDF экспортируется после обновления содержания. Проверяйте числа и разметку при любых последующих изменениях.

До публикации репозитория строка ссылки в отчёте честно указывает «Публикация запланирована отдельно». Перед сдачей замените её действительной ссылкой. Группа БИСТ-24-ПО-1 взята из предыдущего отчёта студента, хранящегося в этом рабочем каталоге.
